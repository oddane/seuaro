# Support

| Need | Where |
|---|---|
| Run a testnet | [RUNNING.md](RUNNING.md) |
| Understand the design | [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and the [docs index](docs/README.md) |
| Report a bug | [Open a bug report](https://github.com/oddane/seuaro/issues/new/choose) |
| Propose a feature or design change | Feature request or ADR proposal in [issues](https://github.com/oddane/seuaro/issues/new/choose) |
| Report a vulnerability | **Privately**, per [SECURITY.md](SECURITY.md) |
| Conduct concerns | Contact the maintainers privately (GitHub profile of @oddane) |

Seuaro is testnet software maintained on a best-effort basis; there is no commercial support or service-level agreement yet.
